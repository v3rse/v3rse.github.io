01 · T3 Code

Added: [2026-11-25 Wed]

T3 Code has become the orchestration layer I use daily. The UI is very good, with a lot of the components I liked in Codex's UI, which I thought was the best-designed ADE.

The best part is using multiple harnesses for their different strengths. Honourable mention goes to the cite feature, which lets me respond to agent feedback inline.

02 · Omarchy

Added: [2026-11-25 Wed]

I've been using Linux since high school. It always meant reading docs and forums to get things working.

Over the past couple of years, Linux has felt more mainstream. Valve's Steam Deck helped turn Linux machines into gaming PCs, and DHH's war with Apple gave us Omarchy.

Before Omarchy, I was already running a hand-configured, riced Arch setup with i3. The killer Omarchy feature for me is being able to configure the OS with AI, right down to creating my own widgets.

It gets constant updates and has become my daily driver.
